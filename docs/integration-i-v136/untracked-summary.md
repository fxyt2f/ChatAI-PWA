## 推奨する管理範囲

| 区分 | 推奨 |
|---|---|
| ルートの実装2ファイル | settings-v136.js / settings-ui-v136.js は製品実装としてGit管理対象 |
| tests/のテスト・fixture・検証スクリプト | 既存150件とI01〜I05追加回帰の再実行に必要。原則管理対象。対象を列挙し、機械的な一括addはしない |
| 本件の最終報告 | report.md、untracked-summary.md、verification-summary.json、changes.diff、before/after-tests.jsonなど再レビューに必要な最小証跡を選ぶ |
| before/assets、before/initial-regressions.js | 修正前再現の依存物。本件のred/greenレビューが終わるまでは保持。リポジトリ内に残すか、別途レビュー用保管へ移すかを後で決める |
| 実装仕様・設計・過去の最終報告 | 版ごとに必要な仕様と最終版を選ぶ。changes.diffは対応する基準点を添えて保持 |
| 比較画像 | 仕様・表示差を示す代表的な比較シートを選ぶ。画像一覧全件を入れる必要はない |
| 原寸素材・中間画像・重複ソース | 再生成可能なものや同一内容は後日の整理候補。今回は保持。Git管理からの除外または別保管を推奨 |
| フルテストログ・OCR入力／結果・大量JSON | 要約／失敗根拠を優先。フルログにはローカルユーザーパスがあり、Git管理時は除外または元ログを保持した匿名化コピーを使う |
| docs/sidebar-background-v136.zip | 46,573,910 bytes。717メンバー（画像685枚）は既存展開物と重複するためGit管理からの除外候補。今回は削除しない |

## 認証情報・個人情報の確認

テキスト本体とZIP内テキスト、画像メタデータの既知キー／秘密鍵／トークン形式検出は0。文字列代入の12候補はテスト用ダミーと確認した。ローカルユーザーパスは実行環境の例外スタックに含まれる。検出位置のみを棚卸しJSONに記録し、認証値そのものを新たに転記していない。

画像は1,895ファイル、SHA-256で重複を除く1,543枚をすべてローカルOCRした。画像読み込みエラー0、空認識0、対象キー／メール／ユーザーパスの検出0。ZIP内685画像はすべてOCR済み画像とハッシュ一致。OCR本文は保存していない。任意の人物名や独自形式の秘密情報を含む全情報の不在を機械検査だけで証明するものではなく、将来Gitへ含める代表画像は通常の内容レビューも行う。

新規ブラウザ検証は隔離Chrome・fixture DBで行った。実利用中のブラウザプロファイル／ユーザーDB、実サービスアカウントにはアクセスしていない。削除・移動・匿名化は今回実施せず、後で整理する際の判断材料としてこの一覧を残す。
