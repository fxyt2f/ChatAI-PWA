# ChatAI PWA v1.36.2 リリース記録

基準は v1.36.1 の main `18c6eb1f99ed8d58ff91cbafd68174086dbd51d0`。リリースブランチは `feature/v1.36.2`。マージと公開結果はPRとGitHub Pagesの実行記録で確認する。

## 変更内容

- タイトル自動生成は最初のユーザーメッセージを使う。一般設定でAPI設定・モデルとシステムプロンプトを選べる。生成中は履歴サイドバーにインジケーターを表示し、手動タイトルを優先する。
- Gemini直APIとOpenRouterのSSEで本文と思考プロセスを逐次表示する。表示中の本文はプレーンテキストで扱い、完了後はDOMPurifyを通したMarkdownで表示する。Geminiの思考署名とPartの順序、OpenRouterの思考情報、ツール呼び出しの継続データを保持する。
- 送信準備中から停止できる。停止時に受信済みの回答と思考を未完了として保存し、APIに送る継続履歴から除外する。ユーザー停止時のキャンセル表示を廃止し、翻訳・校正・対応ツールの通信にも中断を伝える。
- F1〜F10の修正を含む。会話保存の世代・リビジョン照合、再生成候補の保護、重複ツール実行の防止、部分保存を待つ複製、API設定削除の参照照合、SSE断片の復元、構造化思考の集約、ツールループの境界を修正した。

## バージョンと互換性

アプリ表記は `1.36.2`、キャッシュ版は `v1.36.2`。IndexedDBは `DB_VERSION 13`、Dropboxのデータ形式は従来どおり。タイトル自動生成とストリーミング出力は全プロファイル共通で、初期値はOFF。

正式シェルはルートURLと `index.html` を含む16エントリ。 `streaming-v136.js` は `settings-v136.js` の後、 `app.js` の前に読み込む。ハッシュ、ビルドID、検証結果は[機械可読検証記録](v1.36.2-verification.json)に記録する。

## 既知の制約

- SSEの対応先はGemini直APIとOpenRouter。Z.ai、Bedrock、対応外の画像・動画・音声生成は従来方式を使う。独自のOpenAI互換接続先では、型なしIDを繰り返すなど断片の境界が曖昧なSSEに互換性制約がある。
- 外部サービスが受理済みの画像・動画などの生成ジョブは、ブラウザ側の通信停止後も続く場合がある。
- 更新後は開いているChatAI PWAのタブを再読み込みし、v1.36.2へ揃える。混在中の旧版タブの書き込みには、新しい世代・リビジョン照合が働かない。
- API設定の削除が先に確定した場合は、別タブに残る古い選択から参照が保存される場合がある。
- Gemini・OpenRouterの実動作はユーザー確認。今回の自動検証はモックを使用した。実API、実Dropbox同期、実機、Chrome以外のブラウザは今回の検証範囲外。
